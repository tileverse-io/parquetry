# Developer guide

You want to build Parquetry from its sources, try a change, or contribute one. This section is for you. To use Parquetry in an application, start with [Getting started](../getting-started.md) instead.

- [Architecture](architecture.md) shows the modules, their main classes and the path of a read, as C4 diagrams.
- [Build from source](build.md) clones the repository with its test files, builds the modules, runs the tests and builds this site.
- [Releases](releases.md) explains how versions reach Maven Central, and how this site is published.
- [Contribute](contribute.md) lists the conventions followed by a change: formatting, test names, commit messages and license headers.

The source code is on [GitHub](https://github.com/tileverse-io/parquetry), under the Apache License 2.0.
