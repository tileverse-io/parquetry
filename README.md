# Parquetry

Hadoop-free, Java-25, clean-room Apache Parquet 2.x reader+writer with native GeoParquet 2.0 support.

**Status:** under construction. See [`docs/superpowers/specs/`](docs/superpowers/specs/) for the design.

## Build

Requires JDK 25.

```bash
./mvnw verify
```
